# Welcome! This is a companion doc for writing a branching scenario.
# Fill in the brackets below with your own content and send this file
# back. No special software or training is needed to use it.
# A scenario is made of SCENEs and ENDINGs: each scene is a moment in
# the story, and the learner picks one of a few choices to move on.
# Every choice needs a label, a quality, and an arrow to where it
# leads, like this: - Speak up right away (BEST) -> The Next Scene
# The quality is BEST, OK, or POOR, and it tells the learner how
# strong that choice was. The arrow -> points to the name of the next
# SCENE or ENDING, spelled the same as its own SCENE: or ENDING: line
# (capitalization does not matter).
# You can also track a running number through the story, such as a
# trust score, and let a choice only appear past a threshold (shown
# here as an example only, not turned on in this template):
#   TRACK: Confidence (0 to 100, start at 50, visible)
#   - Push back gently (OK, Confidence +10, only if Confidence is at least 40) -> Next Scene
# Everything else is plain writing: describe each situation and write
# what happens at each ending. Leave a bracketed placeholder in place
# if you are not sure what goes there yet; a colleague can fill it in
# later. When you are done, save and share this file with whoever is
# building the lesson.
